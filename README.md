# 颂声起 · 长卷阅读版

此分支 `codex/linear-reading` 将《颂声起》改成从头到尾连续展开的图文长卷。原游戏保留在 `main`，原 GitHub Pages 仍从 `main` 发布。

## 阅读体验

- 十个连续篇章，六关的关键情节以原画面和说明直接呈现。
- 不需要选择、拖拽、答题、解锁或横屏；全文包含在静态 HTML 中，关闭 JavaScript 也可阅读。
- 桌面图文排版、手机竖屏单列、目录跳转、阅读进度、可选背景音乐。
- 仅使用独立的 `her-song-linear-reading:v1` 本地存档键记录上次章节，不读取或修改原游戏存档。
- 保留原版参考文献、艺术创作说明与制作人员图片。

## 本地预览和修改

无需安装依赖，仓库根目录运行：

```sh
node reader/build.mjs
python3 -m http.server 4173 --bind 127.0.0.1
```

打开 http://127.0.0.1:4173/ 。也可直接用浏览器打开 `index.html` 阅读；本地存档受浏览器的本地文件存储策略影响。

`reader/story.json` 是阅读版内容与原画组合数据，来自原编辑器发布快照（revision 3459）。`reader/build.mjs` 生成根目录 `index.html`，验证素材存在并写入图片尺寸，避免延迟加载造成正文移位。样式和增强交互分别在 `reader/reader.css` 与 `reader/reader.js`。

原游戏素材及旧构建文件保留，当前首页只加载阅读版脚本。此分支不修改原站发布设置；不要为了预览阅读版把现有 Pages 的发布分支改掉。
